RAG necesita un modelo de embeddings según tu proveedor (Ollama: ollama pull …; cloud: id de embedding en su documentación). La API key no se devuelve al navegador al recargar la config.

Al cambiar, se rellenan URL base, modelos sugeridos y modo de clave. Ajusta después si tu cuenta usa otros nombres de modelo.

Usa los valores de este formulario (no hace falta guardar). El servidor prueba con GET /v1/models (OpenAI-compatible), GET /v0/models (Cursor Cloud API, https://api.cursor.com, Basic Auth) o GET /api/tags (Ollama), según la plantilla y la URL. La clave de Cursor no sirve en api.openai.com; para Cursor usa plantilla «Cursor Cloud API» y modo Basic.

RAG (retrieval sobre ficheros del repo)

Los agentes trocean texto de agents.local.rag.indexPaths y piden vectores a Ollama (/api/embeddings). Eso exige un modelo de embeddings (p. ej. nomic-embed-text), distinto del modelo de chat. Si falta, verás error 404: abre una terminal y ejecuta ollama pull nomic-embed-text (o el nombre que indiques abajo).
