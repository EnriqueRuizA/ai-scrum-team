AI Scrum Team Orchestrator – Architecture Overview

Built on top of GitHub. Below is a Mermaid diagram and expandable sections that detail each component.

Live Diagram

Visual Diagram (Image)

Agents (agents/*.js)
  • agents/product-owner.js: Generates the PRD and validates deliverables.
  • agents/developer-qa.js: Designs architecture and implements sprints.
  • agents/local-rag-agent.js: Handles RAG for local Ollama deployments.
  • agents/base-agent.js: Base class with shared logic for all agents.
LLM Adapters (src/llm/*.js)
  • src/llm/ollama.js: Wrapper for the local Ollama endpoint.
  • src/llm/local-llm.js: Handles local model execution with or without embeddings.
  • src/llm/openai-compatible-llm.js: Provides an OpenAI‑compatible API surface.
Utilities (lib/*.js)
  • lib/deliverable.js – serialises agent outputs and persists them to outputs/…/artifacts/.
  • lib/parse-llm-json.js – validates and normalises LLM JSON responses.
Client Side (public/*.js)
  • public/parse-llm-json-browser.js – browser‑ready LLM response parser.

Configuration

Runtime options live in config/project-config.json (port, backend, max sprints, etc.). Credentials are stored in config/credentials.json, with placeholders for CI/CD secrets.
